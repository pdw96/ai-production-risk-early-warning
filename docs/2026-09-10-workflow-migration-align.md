## 1. 무엇을 하기로 했나

두 단계다.

1. **공식 아티팩트 사용 원칙을 원문으로 확인하고, 현재 쓰는 아티팩트 아홉을 그 원칙에
   대조해 판정한다.** 맞게 쓰는 것과 잘못 쓰는 것을 가른다.
2. **그 판정에서 「Claude Code 나 GitHub 기능으로 옮길 수 있는 것」만 추려
   워크플로 설계도 한 장을 만든다.**

끝나는 지점은 **설계도 하나까지**다. 이전 작업의 착수는 저자가 이슈를 골라 시작한다 —
이슈 #48 의 「관제탑은 스스로 다음 단계를 시작하지 않는다」와 같은 규칙이다. (사용자 발화)

### 산출물이 사는 곳

**설계도가 완성되기 전까지는 아티팩트로 진행하고, 완성되면 `docs/` 로 옮긴다.** (사용자 발화)

초안 단계에서 아티팩트를 쓰는 것은 원칙과 어긋나지 않는다 — 공식 문서가 드는 용도 중
*"Lay out several design or implementation options side by side"* 와
*"Keep an investigation timeline that fills in while a long task runs"* 에 그대로 해당한다.
완성된 판단은 **기계가 볼 수 있는 곳**에 있어야 하므로 `docs/` 로 내린다.

## 3. 공식 원칙 — 원문 (실측)

`https://code.claude.com/docs/en/artifacts` 에서 그대로 옮긴다.

> An artifact is **a capture of work**: one self-contained page with **no backend**, so it
> **can't store form input** or serve multiple routes.

> a styled page is **more token-intensive** than the same content as terminal text

문서가 드는 용도는 여섯이고 **전부 「보여주는 것」**이다 — PR 워크스루 · 대시보드 ·
대안 나란히 · 진행 중 타임라인 · 링크 공유 · 커넥터 라이브 보드.

토큰 비용을 줄이는 법으로 문서가 직접 드는 셋: 래스터 이미지 대신 SVG/HTML·CSS ·
필요 없는 상호작용 생략 · **큰 데이터는 요약하고 통째로 싣지 않기.**

관련 제약(실측, 같은 문서):

- 단일 페이지 — 상대 링크가 풀리지 않는다. 절 나눔은 페이지 내 앵커로만.
- 발행 파일은 `.html`/`.htm`/`.md` 뿐이고 렌더 크기 상한은 16 MiB.
- 코멘트 감시는 **세션이 도는 동안만** 산다.

## 6. 접근 방식과 기각한 대안

**택한 것** — 관제탑이 이미 세운 **세 층**(규칙 / 상태 / 기록과 왜)을 판정 기준으로
쓰고, 아티팩트마다 「이것이 든 것은 어느 층인가」를 묻는다. ~~**상태 층에 있는 것만
이전 대상**이다~~ — 규칙은 저장소가, 상태는 GitHub 가, 기록은 아티팩트가 든다.
그 위에 「Claude Code 기능 / GitHub 기능 / 그대로 둠」으로 후보를 가른다.

> **정정 (2026-09-10 · 리뷰 지적).** 「상태 층만 이전 대상」은 **틀렸다.** 조사해 보니
> 옮겨야 하는 것의 대부분은 **규칙 층**이었고 — 함정 열여덟 · 보고 통로 · 권한의 선 —
> 설계도의 결론도 그것을 훅 · `CLAUDE.md` · `.claude/rules/` · 스킬로 보내는 것이다.
> **이 문장을 그대로 범위로 읽으면 주된 이전 작업이 범위 밖이 된다.**
> 범위는 **규칙과 상태 둘 다**이고, 아티팩트에 남는 것은 기록이다.
> **원문을 지우지 않고 취소선으로 남긴다** — 이 문서는 게이트 시점의 기록이고,
> 무엇을 잘못 알고 시작했는지가 그 기록의 값이기 때문이다.

**기각한 대안**

| 기각 | 이유 |
|---|---|
| 새 판정 축을 발명한다 | 관제탑의 세 층이 이미 실측 위에 서 있다. 축을 새로 만들면 기존 판단과 대조가 안 된다 |
| 아티팩트 아홉을 전부 읽고 판정한다 | 읽기 비용이 컨텍스트의 큰 몫이고, 셋(Fleet 둘·범위 외)은 사용자가 대상에서 뺐다 |
| 세 번째 리뷰봇 · 마켓플레이스 플러그인 · Plan mode | **이미 #43~#45 로 `wontfix` 닫힘.** 다시 올리지 않는다 |
| 서브에이전트 팀 | #46 `deferred` — 병목이 검토라 생산을 늘리면 미검토 재고만 쌓인다 |
