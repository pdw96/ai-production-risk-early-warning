# 실행 프롬프트 — 개발 파이프라인 관문 설계도 (2026-09-07)

> **이 문서는 무엇인가.** `/align` 게이트를 통과한 뒤 남기는 실행 프롬프트다. 만들
> 것은 **개발 파이프라인 전체의 설계도**이며, 산출물은 **새 아티팩트** 하나다.
> 제품(ERP)의 설계도가 아니라 **그 제품을 만드는 과정**의 설계도다.
>
> **사실은 언제 어떻게 확인됐나.** 아래 실측은 전부 2026-09-07 세션에서
> 저장소·환경을 직접 읽어 확인했다. 확인 명령과 출력은 각 항목에 적었다.
> 라벨은 이 저장소의 관행을 따른다 — **실측 / 발화 / 추정 / 미검증**.

## 무엇을 만드는가

**개발 파이프라인 전체의 관문 지도.** 설계 → 구현 → 검증이 어떻게 흐르고, 각
구간 사이에 어떤 관문이 서며, **그 관문을 통과했다는 것을 무엇으로 관측하는가**를
그린다.

- 대상: 개발 파이프라인 전체 <span>발화</span>
- 완료 조건: **게이트 목록** — 각 관문의 통과 조건이 관측 가능한 형태로 적혀 있다 <span>발화</span>
- 놓을 곳: **새 아티팩트** — ERP 설계도와 나란히 서는 별도 문서 <span>발화</span>

## 왜 지금인가

진단(「파이프라인 조기경보」 아티팩트)이 **층**으로 잘랐다 — 프롬프트·컨텍스트·하네스
아홉 층 중 무엇이 비었는가. 관문은 **같은 사실의 다른 절단면**이고, 실행에 더 가깝다.
층은 "무엇이 없다"를 말하고 관문은 "여기를 지나려면 무엇이 필요하다"를 말한다.
<span>추정 — 사용자가 「왜 지금」을 명시하지는 않았다</span>

## 관문 초안 — 아홉

설계도가 확정할 대상이다. 아래는 실측에서 뽑은 초안이며, 아티팩트를 그리면서
바뀔 수 있다.

셋이 있다(A · B·I는 암묵).** 없는 넷이 전부 **구현 구간**에 몰려 있다.

## 범위 경계

**포함**
- 아홉 관문(또는 그리면서 조정된 수)과 각각의 통과 관측
- 구간 사이의 흐름 — 무엇이 어느 관문을 지나 어디로 가는가
- 현재 상태 표시 — 있음 / 불완전 / 없음

**명시적 제외** <span>발화 — 넷 중 하나를 골라 나머지 셋이 제외됨</span>
- **제품의 데이터 파이프라인** (시드 → 마이그레이션 → 서비스 → API → 화면) — ERP
  설계도가 이미 그리고 있다. 겹쳐 그리면 두 문서가 어긋난다.
- **진단 항목 도입 실행도** — 「파이프라인 조기경보」 아티팩트가 이미 담고 있다.
  설계도는 "어떤 모양이어야 하나"이고 도입 순서는 거기에 있다.
- **CI·훅 배관의 구현 상세** — YAML과 JSON을 적는 일은 설계도의 일이 아니다.

**가정 — 3번 항목이 2점이라 남은 애매함** <span>추정</span>
- 관문 C·D·E·F가 그림에는 놓이되 **설정 파일 내용은 적지 않는다**고 가정한다.
  아티팩트에 YAML을 붙일지 여부는 첫 판을 보고 정한다.

## 제약과 함정 <span>실측</span>

1. **ERP 설계도와 겹치면 안 된다.** 그 문서의 `#order` 절이 이미 **8단계 로드맵**
   (기준정보+PG → 관문 1·2 → 구매반품 → 관문 3·6 → 생산 흐름 → 관문 4·5 →
   관문 7·8 → 경보 층)이다. **거기의 「관문」은 제품의 승인 흐름이고, 이 문서의
   「관문」은 개발 과정의 게이트다 — 같은 낱말이 두 뜻으로 쓰인다.** 새 설계도는
   이 충돌을 처음에 밝혀야 한다.
2. **진단 아티팩트의 재탕이 되면 값이 0이다.** 층 9 · 실행 8 · 기각 4가 이미 있다.
   설계도의 값은 **절단면이 다르다는 것**에서만 나온다.
3. **아티팩트 발행 전 상태 병합이 필요하다.** 진단 아티팩트가 페이지에서 저장된
   버전을 갖고 있어 두 번 거부됐다(publish refused · 2026-09-07 16:00, 16:49).
   새 아티팩트는 별개지만 같은 습관이 필요하다.
4. **설계도 관행이 확립돼 있다.** 판 번호 · 실측/발화/추정 라벨 · 레일 변경 로그 ·
   결정 잠금 카운터(`변동 0`) · SVG 도해. 새 문서도 이 형식을 따른다.
