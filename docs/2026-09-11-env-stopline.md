## 5. 접근 방식과 기각한 대안

설계도의 **대장 19행 + 열린 이슈 20개**에 한 행씩 묻는다:

> **19 다.** 처음 이 문서는 18 로 적었다. 리뷰 지적을 받고 §4 의 표를 다시 세어
> **데이터 행 19**(머리·구분선 제외)임을 확인했다. 한 행이 분류에서 빠졌는지를
> 읽는 사람이 셀 수 없게 되므로, 근거가 되는 수는 세어서 적는다.

> **이것이 없으면 사람이 매번 손으로 실어 날라야 하는가?** (사용자가 고른 판정 기준)

「예」면 **막는 것**, 「아니오」면 **멈춰도 되는 것**이다. 이 기준은 설계도의 진단 한
줄(*"규칙이 파일이 아니라 발화로 전달되고 있다"*)과 같은 축이므로, 앞서 나온 판단과
대조가 된다. (추정 — 기준이 같은 축이라는 것까지가 내 판단이다)

**기각한 대안**

| 기각 | 이유 |
| --- | --- |
| 「틀린 결과가 조용히 지나가는가」로 판정 | 사용자가 고르지 않았다. 이 축을 쓰면 린터·회귀 검사가 앞으로 오는데, 지금 아픈 것은 **규칙 운반**이다 |
| 둘의 합집합 | 최소 집합이 커져 중단선이 늦게 선다 — 중단선을 묻는 물음에 답이 되지 못한다 |
| 2단계 첫 일감을 가상으로 전개해 역산 | 가장 좋은 기준이지만 **가상 전개가 추정을 한 겹 더한다.** 사용자가 고르지 않았다 |
| 새 판정 축을 발명한다 | 설계도가 이미 실측 위에 서 있다. 축을 새로 만들면 기존 판단과 대조가 안 된다 |
| 열린 이슈 20개를 전부 재분류·재정렬 | #48 의 자리를 침범한다. 이 문서는 「무엇이 막는가」만 묻는다 |

`actions/runs` 40건 중 완료된 39건:

```
완료 39건 · 중앙값 5.0분 · 평균 4.9분 · 최소 3.6분 · 최대 6.5분
```

**이 실측은 설계도를 뒤집는 것이 아니라 확인하는 것이다.** 처음 이 문서는 「설계도의
25분이 틀렸다」로 적었는데, 리뷰 지적을 받고 설계도 §4 를 다시 읽으니 **설계도가 이미

- **4분 56초**를 실측으로 적어 두었으며(2026-09-10 · PR #56 · 문서 한 장),
- **`timeout-minutes: 25` 를 소요 시간으로 읽지 말라**고 경고해 두었다.

그러니 낡았던 것은 설계도가 아니라 **#55 의 본문**이었고, 그쪽은 2026-09-11 에
정정됐다(제목이 이미 「값은 1.8분」이다). 이 문서가 더하는 것은 표본 39건이지 정정이
아니다. **틀린 것을 찾았다고 적으면 다음 사람이 이미 기각된 전제를 또 고치러 간다.**

그리고 **이 PR 자체가 그 증거다.** `docs/` 의 마크다운 한 장만 바꿨는데 `validate`

문서 한 장과 코드 변경이 **같은 값을 치른다.**

### 8.2 레인은 맨바닥에서 시작한다 — 이번에 실제로 밟아 본 것 (실측 · 이번에 닫은 미검증 ②)

설계도 §11 이 `SessionStart` 훅을 빈 자리로 올릴 때 근거는 「원인 03」이라는 **추론**
이었다. 이번에 **이 세션에서 직접 밟아** 실측으로 바꾼다.

| 밟은 것 | 결과 |
| --- | --- |
| 기본 `python3` | **3.11.15** — 저장소가 못박은 판은 **3.12**(CI `python-version: "3.12"` · `backend/Dockerfile` `FROM python:3.12-slim`) |
| `backend/.venv` | **없음.** `pytest`·`sqlalchemy`·`fastapi` 어느 것도 안 깔려 있음 |

**`CLAUDE.md` 가 경고한 판 함정이 그대로 물었다.** 3.11 로 그냥 돌리면:

```
   기준이고 지금 3.11 로 돌고 있다. 3.11 의 sum() 은 보정 없이 더해 001 · 004 · 025
   를 하루씩 뒤로 민다.
```

### 8.3 저장소 밖 — 재지 못했다 (미검증)

### 8.4 아티팩트 아홉 (실측 · `Artifact list scope:all`)

**크기 칸이 없는 이유.** §3 의 합의는 「목록·**크기**·갱신 시각까지」였는데, 실제로
`Artifact list` 가 내는 것은 **제목 · URL · 이모지 · 갱신 시각**뿐이다. 크기를 얻으려면
아티팩트를 **한 장씩 읽어야** 하고(허브 한 번이 118.8 KB), 그것은 같은 §3 이
「아티팩트 전문 읽기」로 **제외**한 것이다. 합의가 도구를 잘못 전제했다 — 크기에 기대는
비용 주장을 이 문서가 하지 않는 이유이기도 하다.

라고 적는데 **목록 자체가 이미 여섯**이다.

### 8.5 `mcp` 능력 — 어디까지 닫혔나 (이번에 닫은 미검증 ③ · **절반만 닫혔다**)

**실측** — `mcp` 는 이 계정에서 **선언 가능한 능력 목록에 있다**(`artifact` · `assets` ·
`db` · `downloads` · `mcp` · `room` · `sample` · `self` 여덟. 런타임 계약 0.2.45).
선언 모양은 `capabilities: {mcp: {servers: [{server, tools}]}}` 이고 `server` 는
claude.ai 커넥터의 **표시 이름**이다.

**실측** — 이 세션에서 GitHub 커넥터 도구의 **실제 요청·응답 쌍을 관측했다**
(`list_issues` · `list_pull_requests` · `issue_read` · `pull_request_read`). 공식 지침이
*"관측하지 않은 도구 모양을 추측해 발행하지 말라"* 고 못박으므로, **이 넷에 한해서는
추측 없이 페이지를 쓸 수 있다.**

**실측 — 그리고 값을 깎는 제약이 하나 확인됐다.** `mcp` 를 선언한 페이지는
**공개 링크로 공유할 수 없고**, 호출은 **보는 사람의 계정**으로 나간다.

**미검증으로 남는 것** — 페이지 런타임에서 `claude.use("mcp")` 가 실제로 이 커넥터에
닿아 non-null 을 주는지. **이것은 시험 페이지를 발행해야만 닫힌다**(`use()` 가 유일한
확인 수단이고, `null` 은 「미허용」과 「미지원」을 구분해 주지 않는다). 발행하면
아티팩트가 하나 늘어 `CLAUDE.md` 의 「자식 다섯」과 부딪히므로 **저자에게 물었고,
이 문서를 쓰는 시점에는 발행하지 않았다.**

## 10. 저자 확인 명령지 — 이 세션이 손도 못 대는 것

전부 **미검증**이다. 재려고 시도한 것이 아니라, 설계도 §5 가 403 으로 실측해 둔 자리다.

**이 표는 「보고 적는 것」까지다.** §3 이 「저장소 밖 설정을 **바꾸는 것**」을 명시적으로
제외했고, 여기 값은 전부 미검증이다 — **보지도 않은 상태를 두고 바꾸라고 적으면 안
된다.** 바꿀 것이 있다고 판단되면 그때 별도 이슈로 낸다. 아래 「왜 필요한가」 칸은
**무엇을 보아야 하는지의 근거**이지 처분 지시가 아니다.

| 확인할 것 | 어디서 보나 | 왜 필요한가 |
| --- | --- | --- |
| **Update branch · Wiki** 상태 | Settings → General | #51 이 아직 열려 있는데 실제로 켜졌는지 세션이 못 본다 |
| **auto-merge 가 꺼져 있는지** | Settings → General | 켜는 순간 에이전트의 `enable_pr_auto_merge` 가 실제로 동작한다. **「끄는 것」이 아니라 「그 문을 열지 않는 것」** |
| **룰셋의 필수 검사 문맥** | Settings → Rules → Rulesets | #55 를 집을 때 **잡 이름을 추가하는 구현을 고른 경우에만** 클릭 하나가 필요하다. 지금 할 일이 아니라 **조건**이다 |
| **보안 경보 셋** | Security 탭 (code scanning · secret scanning · Dependabot) | 전부 403. `security-review` 스킬은 **경보 조회를 대신하지 못한다** — 별도의 검토일 뿐이다 |
| **GitHub MCP 커넥터가 두 벌인지** | claude.ai → 설정 → 커넥터 | 설계도 §5 가 두 벌로 실측했다. **무엇이 몇 벌 켜져 있는지를 보고 적는다** — 어느 것을 끄고 남길지는 이 문서가 정하지 않는다(§3 제외). 정리할 값이 있으면 별도 이슈로 |
| **`~/.claude/settings.json` 의 `autoMode`** | 로컬 파일 | 저장소의 같은 이름 파일은 읽히지 않는다. **배열에서 `"$defaults"` 를 빼면 내장 보호가 통째로 사라진다** |
| **Projects 보드** | 브라우저 | 이 세션의 자격증명으로 GraphQL 403. `project` 범위를 든 로컬 `gh` 는 200 이다 |

## 11. 이 문서가 가정 위에 서 있는 자리

- **`mcp` 가 페이지 런타임에서 실제로 커넥터에 닿는지 확인하지 못했다**(8.5). 절반만 닫혔다.
- **저장소 밖의 현재 값 전부**(§10). #51 이 켜졌는지조차 모른다.
- **로드맵 1·2단계와 P1/P2 마일스톤의 대응이 저장소 어디에도 없었다.** 이 문서는 그것을
  정하지 않았다 — 제품 진척이 범위 밖이기 때문이다.

  **이 PR 이 열려 있는 동안 절반이 닫혔다**(2026-09-11). 저자가 축을 둘로 가르기로
  정했고 — **제품**(제품 1단계 ERP Setup · 제품 2단계 ERP 기반 리스크 조기 탐지 Setup)과
  **파이프라인**(P0·P1·P2) — 마일스톤 셋의 `description` 에 그 대응이 적혔다. 같은
  편집에서 P0 의 「2단계」가 **제품 2단계**를 가리킨다는 것도 명시됐다(그 전에는 한
  낱말이 두 축을 가리키고 있었다).

  **저장소에도 이미 있다 — 바로 이 문단이다.** 처음 이 줄은 「저장소 쪽은 아직 비어
